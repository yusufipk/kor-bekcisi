# Kor Bekçisi

Godot 4.7 ile yapılmış üçüncü şahıs hayatta kalma oyunu.

## İndir

[Releases](https://github.com/yusufipk/kor-bekcisi/releases/latest) sayfasından Windows için `KorBekcisi.exe`, Linux için `KorBekcisi.x86_64` dosyasını indir. Linux'ta önce `chmod +x KorBekcisi.x86_64`.

Kaynaktan çalıştırmak için klasörü Godot 4.7 ile aç ve F5'e bas.
